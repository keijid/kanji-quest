# 効果音

ここに mp3 を置き、`sounds.json` にその名前を書くと鳴ります。

| 名前 | 鳴る場所 |
|---|---|
| tap | ボタンを押したとき |
| correct | 正解したとき・5かい れんしゅうで「かけた！」 |
| hint | 1回目にまちがえて、ヒントが出たとき |
| wrong | 2回目もまちがえて、正解を表示したとき |
| evolve | 相棒が進化したとき |
| stageClear | ボスせんでステージクリア・もぎテスト終了 |

例：`tap.mp3` と `correct.mp3` を置いたら `sounds.json` は `["tap", "correct"]`
