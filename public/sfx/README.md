# 効果音

ふだんはアプリの中で合成した音（`lib/sfx-synth.ts`）が鳴ります。
ここに mp3 を置き、`sounds.json` にその名前を書くと、その音に差しかわります。

| 名前 | 鳴る場所 |
|---|---|
| tap | ボタンを押したとき |
| correct | 正解したとき・5かい れんしゅうで「かけた！」 |
| hint | 1回目にまちがえて、ヒントが出たとき |
| wrong | 2回目もまちがえて、正解を表示したとき |
| finish | れんしゅうのセットが おわったとき（ボスせんクリア以外） |
| levelUp | レベルが 上がったとき |
| evolve | 相棒が進化したとき |
| stageClear | ボスせんでステージクリア・もぎテスト終了 |
| ambush | 中ボスが あらわれた（地図で 字を えらんだ とき） |

例：`tap.mp3` と `correct.mp3` を置いたら `sounds.json` は `["tap", "correct"]`
